# unconformstudio.com

The Unconform website, served by GitHub Pages at https://www.unconformstudio.com.
It is a static copy of the former Squarespace site (Nov 2026): plain HTML, CSS and images, no build step.

- Pages: `index.html`, `about.html`, `services.html`, ... (`/about` serves `about.html`)
- Insights posts: `insights/<slug>.html`; list at `insights/index.html`
- Images: `assets/images/`; styles: `assets/css/` (Squarespace's) plus `assets/static.css` (fixes)
- `assets/site.js` runs the mobile menu, accordions and carousels
- Newsletter sign-up forms are Flodesk embeds; contact goes to hi@unconformstudio.com
- Fonts: Figtree (stand-in for Degular, which was licensed through Squarespace) and Work Sans, from Google Fonts

To edit text, change the HTML file and commit; the site updates in a minute or two.
